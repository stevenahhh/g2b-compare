나라장터 Web 프로그램 빠른 시작
================================

1. ZIP 파일을 원하는 폴더에 완전히 압축 해제합니다.
   - ZIP 미리보기 안에서 직접 실행하지 마세요.
   - 가급적 바탕화면처럼 쓰기 가능한 폴더를 사용하세요.

2. START_APP.bat 파일을 더블클릭합니다.

3. 처음 실행할 때 필요한 Python 패키지를 자동으로 준비합니다.
   인터넷 속도에 따라 몇 분 걸릴 수 있습니다.

4. 준비가 끝나면 브라우저에서 아래 주소가 자동으로 열립니다.
   http://127.0.0.1:8765/

5. 프로그램을 종료하려면 실행 창에서 Ctrl+C를 누릅니다.
   실행 중에는 검은 터미널 창을 닫지 마세요.


필수 환경
---------
- Windows 10 또는 Windows 11
- Python 3.12 또는 Python 3.13
- 최초 패키지 설치를 위한 인터넷 연결

Python이 없다면:
https://www.python.org/downloads/
설치 중 "Add python.exe to PATH"를 선택하세요.


나라장터 서비스 키
------------------
전달받은 ZIP에는 실행에 필요한 .env 설정이 포함되어 있습니다.
사용자가 별도로 서비스 키를 입력할 필요가 없습니다.

.env는 GitHub 자동 업데이트에서도 삭제되거나 덮어쓰이지 않습니다.
다만 인증키가 들어 있으므로 ZIP과 .env를 승인되지 않은 사람에게
재배포하지 마세요.


문제 해결
---------
- "package is incomplete"가 나오면 ZIP을 다시 완전히 압축 해제하세요.
- Python 버전 오류가 나오면 Python 3.12 또는 3.13을 설치하세요.
- 8765 포트 오류가 나오면 기존 실행 창을 모두 닫고 다시 실행하세요.
- 브라우저가 자동으로 열리지 않으면 직접 접속하세요.
  http://127.0.0.1:8765/


개발자용
--------
- 환경 점검만 실행:
  powershell -ExecutionPolicy Bypass -File scripts\start-user.ps1 -CheckOnly

- 브라우저를 열지 않고 실행:
  powershell -ExecutionPolicy Bypass -File scripts\start-user.ps1 -NoBrowser
