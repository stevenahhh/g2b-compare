# Limitations

- 최초 full sync는 26년 범위와 문서상 일일 1,000회 한도 때문에 여러 날
  걸릴 수 있음. 완료 전에는 source snapshot과 검색 release를 게시하지 않음.
- 검색 결과는 마지막으로 게시된 API snapshot 기준이며 나라장터 웹 화면의
  실시간 상태와 차이가 날 수 있음.
- 상품 설명 보강만 종합쇼핑몰 웹 페이지의 공개 SSO와 관찰된 WebSquare
  endpoint를 사용함. 이 경로는 공식 OpenAPI가 아니며 사이트 계약이 바뀔 수
  있음. 인증이나 schema가 달라지면 전역 dispatch를 멈춤.
- API record의 동시 출현을 본품·추가선택품목 부모 관계로 해석하지 않음.
  추가선택 관계는 승인된 workbook 근거가 있을 때만 표시함.
- 비교 후보는 같은 카테고리·세부 카테고리·정규화 품목명으로 제한됨.
  다른 카테고리의 의미상 유사 제품은 추천하지 않음.
- 가격은 금액이 양수이고 단위가 서로 비교 가능할 때만 점수에 반영됨.
  누락·0원·혼합 단위는 가격 비교 불가로 표시함.
- 공급자가 안정적인 상품 공유 키를 주지 않으면 나라장터 상세 링크 대신
  물품 ID와 종합쇼핑몰 홈 링크를 제공함.
- 현재 상품 설명 rollout 범위는 수집된 본품 27,757개 전부임. 추가선택품목과
  아직 수집되지 않은 상품은 범위 밖임.
- 설명 HTML이 참조하는 이미지, font, media의 파일 bytes는 내려받거나 저장하지
  않음. 참조 tag는 보존된 `decoded_html`에 남을 수 있지만 plain text에서는
  제외됨. 물품 이미지는 API가 제공한 URL 근거만 보존하며 로컬 이미지 저장소를
  운영하지 않음.
- `missing`은 관찰 시각에 게시된 설명이 없었다는 뜻일 뿐 영구적으로 설명이
  없다는 뜻이 아님. 다시 확인하려면 명시적으로 `--retry-missing`을 사용함.
- Compact runtime DB에는 아직 설명 observation과 raw 참조를 넣지 않음. 앱
  consumer를 설계하기 전까지 설명은 일반 검색, 비교, 견적 화면에 나타나지 않음.
- 이번 버전의 랭킹·파서 평가는 결정론적 hand fixture와 50k 성능 corpus를 사용함.
  별도 사람 평가자 2명의 2,000쌍 판단, disagreement adjudication, 500행 parser
  gold는 수행하지 않았으므로 사람 평가 기반의 품질 수치는 제공하지 않음.
- 최종 실행 검수에 사용한 fixture는 실제 나라장터 전체 카탈로그 수집 완료를
  의미하지 않음. 실제 검색 범위는 마지막으로 게시된 active release의 snapshot에
  한정됨.
