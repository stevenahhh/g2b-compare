# 업무 자동화 툴 개발 계획서

### 개발 현황 및 잔여 기간 계획서

인공지능공학부 안순광 | 2026 하계 현장실습 | 작성일 2026-07-28

---

## 1. 개요

본 문서는 현장실습 기간 중 개발해 온 나라장터 품목 검색·관급 내역서 작성 자동화 프로그램의 현재까지 진행 상황과 잔여 실습 기간에 수행할 업무 계획을 정리한 것입니다. 본 프로그램은 조달청 나라장터 종합쇼핑몰 품목을 검색하여 관급 공사 내역서 작성에 필요한 단가조사·대조견적을 자동화하고 나아가 표준품셈 기반 원가 계산까지 연결하는 것을 목표로 합니다. 관급 내역서 작성 실무에서 가장 반복적이고 시간이 많이 드는 품목별 3개 업체 대조 견적과 품셈·일위대가 산출 과정을 처리합니다.

## 2. 개발 배경 및 목적

- 관급 내역서의 단가조사 시트는 품목마다 서로 다른 3개 업체(A·B·C사)의 규격·물품식별번호·단가를 직접 검색·비교하여 채워야 하며 품목 수가 많을수록 수작업 부담이 급증합니다.
- 이어지는 일위대가표·표준품셈·원가계산서는 노무비·재료비 단가와 수량을 반복 대입하는 정형화된 계산이 대부분입니다.
- 따라서 G2B 검색 → 단가조사 → 품셈 계산 → 내역서 출력을 하나의 파이프라인으로 자동화하면 작성 시간을 단축하고 단가 누락·오기 등 휴먼 에러를 방지할 수 있습니다.

## 3. 현재까지 개발 완료 사항

파이프라인의 앞단(품목 검색·대조 견적)을 우선 구현하여 동작을 검증하였습니다.

- G2B 실시간 품목 검색: 다수공급자계약·일반단가·제3자단가 3개 계약유형을 품명 기준으로 동시(병렬) 조회하고 동일 물품을 통합하여 현재 유효한 계약 단가를 제시합니다.
- 대조군 비교 로직: 규격 유사도 기반 랭킹에 더해 계약업체 다양성을 적용하여 서로 다른 업체 후보를 우선 배치하여 단가조사의 A·B·C사 구조에 대응합니다.
- 로컬 웹 GUI 및 수동 데이터 동기화: 실시간 검색 화면과 필요 시 최신 데이터를 일괄 수집하는 수동 동기화 기능을 제공합니다.
- 품질 확보: 전 구간 자동화 테스트·정적 타입 검사를 통과하는 상태로 관리하고 있습니다.

## 4. 남은 기간 개발 범위

잔여 실습 기간에는 검색 결과를 실제 내역서 산출물로 연결하는 뒷단을 개발합니다. 확보한 실제 관급 내역서 표본과 우수조달물품 현황 자료를 기준으로 시트 구조·수식 패턴을 분석하여 자동화 규칙을 도출합니다.

내역서 작성은 크게 네 단계로 이어집니다. **이 중 잔여 실습 기간에 실제로 개발을 완료할 범위는 ① 단가조사 자동화와 ② 품셈·일위대가 산출까지입니다.** 두 단계가 작성 시간의 대부분을 차지하고 규칙이 명확해 자동화 효과가 가장 크기 때문입니다. ③ 원가계산·집계와 ④ 내역서 출력은 앞 두 단계의 산출물이 안정화된 뒤에 착수하는 차후 목표로 둡니다.

### 4-1. 이번 기간 개발 범위

| 단계 | 개발 범위 | 산출물 / 자동화 대상 |
|---|---|---|
| ① 단가조사 자동화 | 검색·대조 결과를 단가조사 시트 열 구조에 자동 매핑 | 품목별 A·B·C사 규격·물품식별번호·단가 채움 및 최저가 기준 적용단가 산정 |
| ② 품셈·일위대가 산출 | 표준품셈 기반 노무비·재료비 산출 및 일위대가표 생성 | 품(공량) 조회 후 노임단가 대입하여 일위대가 자동 산출 |

**① 단가조사 자동화**

- 이미 구현한 실시간 검색·대조군 비교 결과를 단가조사 시트의 열 순서에 맞춰 그대로 배치합니다.
- 한 품목에 대해 서로 다른 계약업체 세 곳을 A사·B사·C사 자리에 채웁니다.
- 각 업체의 규격과 물품식별번호와 계약단가를 함께 기록하여 근거를 남깁니다.
- 세 후보 중 최저가를 적용단가로 산정합니다.
- 완성된 표를 엑셀에 그대로 붙여넣거나 파일로 내려받을 수 있게 합니다.

**② 품셈·일위대가 산출**

- 표준품셈 자료를 구조화하여 품목별 공량(품)을 조회할 수 있는 형태로 정리합니다.
- 조회한 공량에 노임단가를 대입하여 직접노무비를 계산합니다.
- 재료비와 노무비를 합산한 일위대가표를 품목 단위로 생성합니다.
- 수량산출서의 수량과 연결하여 품목별 합계 금액까지 산출합니다.
- 계산 과정을 화면에서 확인할 수 있게 하여 담당자가 검토·보정할 수 있도록 합니다.

### 4-2. 차후 목표

| 단계 | 개발 범위 | 산출물 / 자동화 대상 |
|---|---|---|
| ③ 원가계산·집계 | 도급/관급 집계표·원가계산서 자동 산출 | 재료비·노무비·경비 집계 및 관급/도급 분리 계산 |
| ④ 내역서 출력 | 표지~수량산출서까지 내역서 워크북 일괄 생성 | 검색에서 문서 출력까지 이어지는 전 구간 파이프라인 완성 |

## 5. 자동화 목표 수준

관급 내역서는 사업별로 시트 구성과 수식이 일부 상이하므로 확보한 표본을 기준으로 공통 CCTV·정보통신 공사 유형을 우선 완성하고 이후 표본을 늘려가며 대응 범위를 확장합니다. 사용자는 자동 산출된 결과를 검토·보정만 하면 되도록 하여 '검토 가능한 초안 자동 생성' 수준을 **최종 목표**로 합니다.

## 6. 잔여 기간 수행 계획

- 잔여 실습 기간 동안 본인은 ① 단가조사 자동화를 먼저 완성한 뒤 이어서 ② 품셈·일위대가 산출을 개발합니다. 각 단계를 마칠 때마다 실제 내역서 표본과 대조하여 결과를 검증하겠습니다.
- ③ 원가계산·집계와 ④ 내역서 출력은 이번 기간의 완료 범위에 포함하지 않습니다. 다만 앞 단계를 개발할 때 이후 확장을 고려한 구조로 설계하여 차후 이어서 개발할 수 있게 준비하겠습니다.
- **각 단계가 독립적으로 분리되어 있어 단계별로 나누어 진행·검증할 수 있으므로 일정 배분과 우선순위 조정이 유연합니다.**
- **현장실습 중 배정되는 다른 업무의 종류나 강도와 무관하게 병행하여 충분히 소화할 수 있습니다. 다른 업무가 늘어나더라도 본 과제 진행에는 지장이 없도록 관리하고 있습니다.**

## 7. 인수인계 및 문서화

잔여 실습 기간의 개발이 마무리되는 시점에는 프로그램 자체뿐 아니라 이어받아 개발을 계속할 수 있도록 관련 문서 일체를 함께 정리하여 전달하겠습니다.

- 프로그램의 전체 구조와 각 모듈이 맡는 역할을 정리한 설계 문서를 제공합니다.
- 단가조사와 품셈·일위대가 산출 로직을 만들 때 적용한 규칙과 판단 기준을 정리한 방법론 문서를 제공합니다.
- 실행 환경을 구성하는 절차와 데이터를 갱신하는 절차를 정리한 운영 안내서를 제공합니다.
- 검증에 사용한 테스트 항목과 결과를 정리하여 이후 기능을 추가할 때 기준으로 삼을 수 있도록 합니다.
- ③ 원가계산·집계와 ④ 내역서 출력을 이어서 개발할 수 있도록 남은 작업 범위와 참고할 설계 방향을 별도로 정리하여 전달합니다.

이를 통해 후속 담당자가 개발 배경과 진행 상황을 빠르게 파악하고 바로 이어서 작업할 수 있도록 하겠습니다.
