# 나라장터 종합쇼핑몰 API 참고자료

이 디렉터리는 나라장터 종합쇼핑몰 유사 물품 검색 앱을 설계·개발할 때 기준으로 삼을 원본과 비식별 메타데이터를 보관함.

## 보관 파일

- `조달청_OpenAPI참고자료_나라장터_종합쇼핑몰품목정보서비스_1.3.docx`: 사용자가 제공한 조달청 OpenAPI 참고문서 원본의 무손실 복사본임.
- `나라장터_종합쇼핑몰품목정보서비스_개발계정_비식별요약.md`: 공공데이터포털 개발계정 화면에서 API명, 승인 상태, 이용 기간, 엔드포인트, 오퍼레이션, 호출량만 추린 비식별 요약임.

## 보안 원칙

개발계정 화면 원문에는 인증키가 포함될 수 있으므로 작업공간에 복사하지 않음. 서비스 키는 서버 환경변수나 비밀 저장소에서만 읽고, 브라우저 코드·URL 로그·저장소 파일에 기록하지 않아야 함.
